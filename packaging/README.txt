  ══════════════════════════════════════════════════════════

  HOW TO RUN
  ──────────
  1. Extract this whole folder anywhere (Desktop is fine).
  2. Double-click  "Start Ghoststream.bat"
  3. Your browser opens the app at http://localhost:8420/

  That's it. No installation, no Node.js, no admin rights —
  the launcher includes its own tiny local server.

  To quit: close the black console window (or press Ctrl+C).

  ───────────────────────────────────────────────────────────
  WHAT IS THIS?
  ─────────────
  A Netflix-style app for streaming and downloading 110+
  hand-curated PUBLIC DOMAIN classics — horror, film noir,
  sci-fi, silent comedy (Keaton! Chaplin!), vintage cartoons,
  westerns, Hitchcock thrillers and beloved B-movies.

  Everything is streamed and downloaded directly from the
  Internet Archive (archive.org). 100% legal, 100% free,
  no ads, no accounts, no tracking.

  ───────────────────────────────────────────────────────────
  ANDROID / IPHONE?
  ──────────────────
  Host these same files on any web server (or GitHub Pages)
  and open the site in Chrome — then use "Add to Home screen"
  to install Ghoststream as a full-screen app. The app is a
  PWA (works offline for browsing after the first visit).

  ───────────────────────────────────────────────────────────
  FEATURES
  ─────────
  * Instant search across the whole catalog  (press /)
  * My List + Continue Watching (saved on this device)
  * Real downloads with progress bar — files are yours forever
  * Custom video player: resume, speed, fullscreen, keyboard
    shortcuts (space, arrows, F, M), 10-second skips
  * Gamepad/TV-friendly navigation, ambient ghost mode

  ───────────────────────────────────────────────────────────
  NOTES
  ─────
  * Streaming requires an internet connection (videos come
    live from archive.org).
  * Some classic films only exist in 480p — that's history
    for you.
  * Everything here is in the public domain in the US.

  Enjoy the show.  🍿👻
